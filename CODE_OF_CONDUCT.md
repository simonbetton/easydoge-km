# Code of Conduct

This project should be a useful, technically serious place to build Dogecoin self-custody software.

## Expected Behavior

- Treat other contributors with respect.
- Keep technical disagreement specific and evidence based.
- Assume public issues and pull requests are visible to users who may rely on this SDK for financial software.
- Do not post private keys, seed phrases, wallet backups, or customer data.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing secrets or private vulnerability details before coordinated disclosure.
- Repeated off-topic or bad-faith participation that blocks maintainers or contributors from doing project work.

## Enforcement

Maintainers may hide comments, close issues, reject pull requests, or block accounts when behavior puts contributors or users at risk. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).
