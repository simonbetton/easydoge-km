# easydoge-km

Rust core crate for EasyDoge KM.

This crate is the canonical implementation for Dogecoin BIP39/BIP32/BIP44 key derivation, address handling, WIF import/export, message signing, transaction signing envelopes, and multisig descriptor helpers.

See the workspace [README](../../README.md) and [API guide](../../docs/API.md).
