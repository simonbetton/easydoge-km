# easydoge-km-cli

CLI and Ratatui TUI for EasyDoge KM.

The `easydoge-km` binary calls the Rust core implementation directly and exposes engineer workflows for mnemonic handling, account derivation, watch-only address derivation, WIF handling, message signing, transaction signing envelopes, and multisig operations.

See the workspace [README](../../README.md) and [API guide](../../docs/API.md).
